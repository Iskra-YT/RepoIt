# AGENTS.md

Guidelines for AI coding agents and contributors working in this repository.

## Commit messages

- Write every commit message in **English** (subject and body). Polish is not
  allowed in commit messages, even when the feature is described in Polish docs
  or communication.
- Follow conventional style: short imperative subject (`Add`, `Fix`, `Update`,
  `Remove`), optional body with details, no emoji unless already used in the
  repo history.
- Example: `Fix feed card dedupe on retry` instead of `Poprawka dedupe karty feed`.
